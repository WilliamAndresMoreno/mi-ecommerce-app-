# 🛒 Mi Ecommerce App - Prueba Técnica

Este es un proyecto full stack desarrollado como parte de una prueba técnica. Consiste en una tienda en línea con autenticación, visualización de productos y funcionalidades básicas de carrito y pago.

---

## 🔧 Tecnologías Utilizadas

### 🖥️ Frontend
- React con Vite
- Tailwind CSS
- JavaScript (ES6+)
- React Router DOM

### 💻 Backend
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server / LocalDB
- JWT (JSON Web Tokens)

---

##  Instrucciones para Ejecutar

### 1. Backend (ASP.NET Core)

```bash
cd Backend
dotnet restore
